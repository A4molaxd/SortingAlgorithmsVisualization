# Sorting Algorithms Visualization

This project contains several Python files with the code of various known sorting algorithms. 

The code generates a random order of values, these values are then repeatedly passed to the function containing the algorithm and a function that shows the values being sorted in screen.

## Algorithms

Here you can see the Wikipedia description of the implemented algorithms:

- Bubble Sort: https://en.wikipedia.org/wiki/Bubble_sort.
- Cocktail Shaker Sort: https://en.wikipedia.org/wiki/Cocktail_shaker_sort.
- Comb Sort: https://en.wikipedia.org/wiki/Comb_sort.
- Gnome Sort: https://en.wikipedia.org/wiki/Gnome_sort.
- Merge Sort: https://en.wikipedia.org/wiki/Merge_sort.
- Odd-even Sort: https://en.wikipedia.org/wiki/Odd%E2%80%93even_sort.
- Quicksort: https://en.wikipedia.org/wiki/Quicksort.
